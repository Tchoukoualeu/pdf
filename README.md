# PDF Experience

Split a PDF into one file per page. A 3-page document becomes 3 PDFs.

Everything runs in the browser. Files never leave this device.

## Run locally

```bash
npm install
npm run dev
```

Open the local URL Vite prints (usually `http://localhost:5173`).

## Use

1. Drop a PDF onto the page, click to choose one, or try the 3-page sample.
2. Download a single page, or download all pages as a zip.

## Scripts

| Command | What it does |
| --- | --- |
| `npm run dev` | Start the local app |
| `npm test` | Run split tests |
| `npm run build` | Typecheck and build for production |
| `npm run preview` | Preview the production build |
